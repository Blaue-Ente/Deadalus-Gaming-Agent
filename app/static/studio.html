    Blockers

    Plans
    
          
    
          
          
    
            
            
          
    
          
    
            
            
            
    
              
            
    
            
    A manual plan starts as a draft. Approve it, as with a generated one, when its steps are ready.
    
          
    
          
    
          
    Plans are global. Generate writes a draft with one agent turn. Approve creates tasks and does not run them. Delete removes the plan and its steps and keeps tasks.
    
        
    
        
    
          
    Discoveries
    
          
    
          
          
    
            
          
    
          
    
          
    Discoveries are global. Approve writes a lesson and schedules a model call. Reject only changes status.
    
        
    
        
    
          
    Skill draft
    
          
    
          
          
          
          
    
            
            
            
            
          
    
          
    
          
    
          
    
          
    
          
    
          
    
            
            
          
    
          
    Skills are global. Start sends one configured-provider call and does not search the web. Generate returns files in that response. Nothing is published.
    
        
    
        
    
          
    Reference brief
    
          
    
          
          
    
            
          
    
          
    
          
    A reference brief is global. Scout searches DuckDuckGo and calls alltoken:deepseek-v3.2. It does not use the Studio provider and it does not save a project file.

    Connections

    MCP servers
    
        
    Enabling adds the server to the MCP list. It runs a local program when it is first used.
    
        
    
        
    Durability
    
        
    
        
    Kernel export
    
        
    Exports a snapshot of this product to a branch of its own, with fresh history. The main branch is never touched and secret files are never included.
    
        
    
        
    Upgrade pool
    
        
    Scans the new upgrade candidates with the model and sends proposals to the Outbox. It makes model calls.
