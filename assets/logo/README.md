# Daedalus mark

Labyrinth (plan, craft, games) plus a compass-bird (Daedalus the inventor).
Gold `#c9a227` on `#14110d` — the same palette as Studio.

| File | Use |
|---|---|
| `daedalus.svg` | Vector source (README, print) |
| `daedalus.png` | 512×512 raster (Studio, Command Center) |
| `daedalus-avatar.png` | 192×192, under 200 KB — **GitLab project avatar** |
| `daedalus.ico` | Windows shortcut / favicon |

Shipped copies: `app/static/daedalus-mark.png`, `app/static/favicon.ico`, `ui/static/daedalus-mark.png`.

## GitLab project avatar

Git does not set the GitLab header icon. After merge, a maintainer uploads the file:

1. Open https://gitlab.com/Blaue-Ente/deadalus-agent-0/edit
2. **Settings → General → Project avatar**
3. Choose `assets/logo/daedalus-avatar.png`
