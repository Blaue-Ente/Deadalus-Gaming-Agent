Настройки за GitHub / GitLab push & clone и устойчивост на Playground проекти при redeploy. Токените се задават в Replit Secrets или Integrations — не в този UI.

🐙 GitHub

Зареждане…

Как да свържеш GitHub за 1-клик push:

  1. Replit Integration ≠ push — дава read/clone, не създава repos
  2. github.com → Settings → Developer settings → Personal access tokens
  3. Classic token → отметни scope repo (пълен достъп)
  4. Replit → Secrets → GITHUB_TOKEN = новият PAT
  5. Redeploy на Daedalus
  6. Playground → ⬆ GitHub (без prompt — автоматично нов repo по slug)

Fine-grained алтернатива: Contents (Read/Write) + Administration (Read/Write) за твоите repos.
