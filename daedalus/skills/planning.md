# SKILL: Планиране на многоетапна задача

**Кога**: owner-ската заявка изисква ≥3 стъпки (например "анализирай Х и предложи план", "имплементирай Y модул").

**Стъпки**:
1. **ПЪРВО** emit-вай `<NEED_PLAN: step1 | step2 | step3 | ...>` (минимум 3, максимум 7 стъпки, всяка на български, ≤80 символа).
2. PlanStore запазва плана в Replit DB → owner вижда го в admin UI.
3. Изпълнявай стъпките една по една. След всяка → `<NEED_PROGRESS: task | pct | msg>`.
4. Накрая — кратко резюме: какво е завършено, какво остава, проблеми.

**Правила**:
- НЕ pollute плана с "ще помисля", "ще проверя" — само конкретни действия.
- Ако стъпка се провали 2 пъти → marked as blocked, продължи със следващата.
- Ако цялата задача отнема >5 мин → spawn worker (`NEED_WORKER: deep | task`).

**Anti-patterns**:
- НЕ започвай работа без план при многоетапни задачи (трудно е за owner да следи).
- НЕ описвай плана в свободен текст — използвай NEED_PLAN маркера.
